# ComKey（コメントキーワード検出器）

Twitch のチャットを解析し、コメント内に設定したキーワードが含まれていた場合、  
その部分だけを棒読みちゃんではなく指定した音声ファイルで再生するツールです。

## 2. 概要

- Twitch からチャットデータを取得  
- コメント内のキーワードをリアルタイムで検出  
- 該当部分を棒読みちゃんではなく、指定した音声ファイルで再生  
- 棒読みちゃんと併用して使用します  
- [ココ](https://github.com/mlvier/ComKey/releases)から最新版の `comkey.exe` をダウンロードするだけで利用可能  

---

## 3. 使い方

1. ComKey と棒読みちゃんを起動
2. 「認証する」をクリック → ブラウザで Twitch 認証
3. ウィンドウに「認証されています」と表示されれば成功  
4. 「開始」を押すとチャット読み上げが始まります  
5. キーワード設定  
   - 「キーワード」欄と「音声ファイル」欄を入力し「追加」を押す  
   - キーワード一覧で音量バーによる再生音量調整が可能  
   - 右クリックでキーワード削除が可能  

---

## 4. 注意事項

- 棒読みちゃんは別途ダウンロードが必要です  
- `twitch_token.json` は外部に流出しないよう厳重に管理してください  
- 棒読みちゃんを起動してから「開始」を押さないと読み上げが行われません  
- 「認証されています」と表示されている場合、再認証は不要です  
- 設定ファイルは「data」フォルダ内から動かさないでください  
  - `keywords.json`：キーワード設定  
  - `twitch_token.json`：Twitch トークン  
- 起動中に JSON ファイルを直接編集しても、内容は反映されません  

---

## 5. 補足

- 本ツールは **データ収集を一切行っていません**  
- 作者側にチャット内容が送信されることもありません

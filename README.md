# ComKey

## ＝＝＝　はじめに　＝＝＝

何があっても責任取りません取れません。  
でも、何かあったらTwitterアカウント（@vier_ml）まで連絡ください。  
聞くことはできます。


## ＝＝＝　概要　＝＝＝

Twitchからチャットデータを入手してコメントを棒読みちゃんに読ませるとき、  
そのコメントの中に設定したキーワードが含まれていたら、  
その部分を別の音声に変えるものです。

[ここ](https://github.com/mlvier/ComKey/releases)から最新版の「comkey.exe」をダウンロードするだけで使えます。


## ＝＝＝　使い方　＝＝＝

* これと棒読みちゃんを起動する  
* 「認証する」を押す→ブラウザで認証  
* 「認証されています」と表示されたら「開始」を押す  
* コメントに設定したキーワードが含まれていたとき、その部分だけ棒読みちゃんでなく音声ファイルを再生する
  * キーワード設定は、「キーワード」欄と「音声ファイル」欄にそれぞれ適した内容を入力し、「追加」を押すとできます
  * キーワード一覧で、選択したキーワードに対応した音声ファイルの再生音量を上のバーで調整できます
  * キーワード一覧で、選択したキーワードを右クリックすると削除案内が出ます


## ＝＝＝　注意　＝＝＝

* 棒読みちゃんは別途ダウンロードが必要となります
* 「twitch_token.json」の中身は流出しないように気を付けてください
* 棒読みちゃんが起動しているときに「開始」を押さないとチャットを読ませることができません
* （主に2回目以降）「認証されています」と表示されているときは再度認証をする必要はありません
* キーワードデータは「keywords.json」に、Twitchデータは「twitch_token.json」に入っています
* これを起動中に直接jsonファイルを変更しても、その内容は反映されません

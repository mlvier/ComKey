# ComKey

## ＝＝＝　はじめに　＝＝＝

何があっても責任取りません取れません。  
でも、何かあったらXアカウント（@vier_ml）まで連絡ください。  
聞くことはできます。


## ＝＝＝　概要　＝＝＝

コメントを棒読みちゃんに読ませるとき、  
Twitchからチャットデータを入手して  
そのコメントの中に設定したキーワードが含まれていたら  
その部分を別の音声に変えるものです。


## ＝＝＝　使い方　＝＝＝

* これと棒読みちゃんを起動する  
* 「認証する」を押す→ブラウザで認証  
* 「認証されています」と表示されたら「開始」を押す  
* コメントに設定したキーワードが含まれていたとき、  
その部分だけ棒読みちゃんでなく音声ファイルを再生する


## ＝＝＝　注意　＝＝＝

*  「twitch_token.json」の中身は流出しないように気を付けてください
*  棒読みちゃんが起動しているときに「開始」を押さないとチャットを読ませることができません
*  （主に2回目以降）「認証されています」と表示されているときは再度認証をする必要はありません
*  キーワードデータは「config.json」に、Twitchデータは「twitch_token.json」に入っています


## ＝＝＝　補足　＝＝＝

* データ収集は一切行っておりません
